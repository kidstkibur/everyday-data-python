# Everyday Data with Python

A collection of small Python exercises exploring fundamental data analysis concepts, statistical calculations, and programming techniques.

## About the Project

This repository documents my journey in learning Python for data analysis as part of my Data Science learning path.


## Current Topics

### Descriptive Statistics

The first exercise calculates two measures of central tendency using a sample dataset:

- **Mean:** Calculates the arithmetic average of the dataset.
- **Median:** Identifies the middle value of the dataset, or the average of the two middle values when the number of observations is even.

## Technologies

- Python 3
- Git and GitHub

## Getting Started

### Prerequisites

Install Python 3 on your computer.

### Run the Script

Clone this repository:

```bash
git clone https://github.com/kidstkibur/everyday-data-python.git
```

Navigate to the project directory:

```bash
cd everyday-data-python
```

Run the Python script:

```bash
python main.py
```

## Example Output

For the sample dataset, the script calculates:

```text
Mean: 15.583333333333334
Median: 14.0
```
